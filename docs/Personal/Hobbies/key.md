
# 半音阶口琴转调

如何把任何调性的简谱转换成C调使用半音阶口琴演奏

我们在演奏的时候有的谱子不是C调的，但是我们手边也没有那个调性的10孔口琴。虽然可以使用第二把位或者其他把位演奏。但是这个有一定的学习门槛。
我们如果使用C调半音阶口琴来转调演奏原来调性的曲子？有不同的方法。我们认为最简单的是把不同调性的曲谱转换成C调的曲谱（因为我的半音阶口琴是C调），这个需要你把原来的曲谱打印出来，然后把每个音符使用下面的转盘转换一下，在打印的谱子上重新标准。

调性转换转盘的成品长的这样。举个例子，当需要把降B调转换成C调的曲谱时，把中心的小盘的1 对准最外圈的调性，比如bB调。这样，你看着最小圈的每个音阶（代表原来的曲谱的音阶），比如7，然后看中间环（目标调性）是6，就是说降B调的7就是C调的6，再比如，看降B的1，就是C调的#6，注意这个在半音阶口琴上需要使用按键。
请注意这个转盘没有考虑高音和低音，你需要自己注意原来谱子的高音和低音，以免发生错误。
标注曲谱还是需要一点时间的，而且手写也不一定很美观，如果需要制作更精美的曲谱，我个人推荐使用open source软件Lilypond和Jianpu-ly程序，这个也需要一定的学习门槛，对于程序员可能比较友好。
我听说如果使用五线谱，是最长期的解决方案，也不需要转调，目前我不太熟悉五线谱，而且五线谱的中国流行歌曲的谱子不是很多，大部分都是简谱。
如果以古典音乐为主，还是直接看五线谱。
