# 2015 Lexus RX350 A/C Flow Sensor Fix

This is my repair note for the air conditioning issue on the 2015 Lexus RX350.
The A/C stopped cooling during the first week of June 2026. The blower still
worked, but the compressor was not running.

## Symptoms

- A/C stopped cooling.
- Blower still worked.
- Relay and fuse checks did not show an obvious fault.
- Compressor would not engage until the flow sensor magnet workaround was
  tested.

## Research

The useful clue came from this ClubLexus thread:
[RX350 2010/2011 Air conditioning DTC B1479 cheap solution](https://www.clublexus.com/forums/rx-3rd-gen-2010-2015/824215-rx350-2010-2011-air-conditioning-dtc-b1479-cheap-solution.html).

The thread describes an A/C flow sensor issue where the control system may see
an out-of-range signal and refuse to engage the compressor. Several owners
reported that placing a small magnet near the compressor flow sensor allowed the
compressor to run again.

## Parts and materials

- Replacement A/C flow sensor, purchased but not installed.
- Small magnet for testing the sensor workaround.
- R-134a refrigerant can.
- A/C pressure gauge.

## Work performed

1. Checked relay and fuse first.
2. Bought a replacement sensor.
3. Tried to reach the sensor on the compressor, but access was extremely tight.
4. Used the magnet trick near the sensor instead.
5. Confirmed the compressor started running again.
6. Released a small amount of refrigerant.
7. Refilled the system with a new can of R-134a to the target pressure.
8. Confirmed the A/C started cooling again.

## Current status

The A/C is cooling again. The replacement sensor is still not installed because
the sensor location is difficult to access. The working fix is currently based
on the magnet workaround.

## Follow-up

On June 9, 2026, clean up the work area and reinstall the plastic covers below
the engine and above the work area so the car is back in proper condition.

I also want to get a few small magnets and mount one more cleanly, instead of
