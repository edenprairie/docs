# Personal Library Guide

This site is a personal library. It is organized for retrieval: the
right note should be easy to find months later, even if the original context is
gone.

## Main shelves

- **Personal**: travel, identity, hobbies, and personal lists.
- **Home & Family**: property, family, finance, legal, and household reference
  documents.
- **Technology & Homelab**: servers, networking, storage, tools, and technical
  setup notes.
- **Career & Learning**: professional notes, communication ideas, career
  references, and learning material.
- **Reference**: reusable guides that do not belong to a single life area.
- **Blog**: dated entries, site updates, and short reflections.

## Maintenance rules

Use folders for stable life areas, not temporary moods. When a new note becomes
worth keeping, place it in the closest shelf and add it to
`sidebars.js`. If it is only a time-based update, publish it as a blog post
instead.

Prefer descriptive filenames for new documents. Short legacy filenames can stay
where they are until there is a good reason to move them.

## Suggested future cleanup

The current sidebar preserves existing document URLs where practical. Future
cleanup can gradually rename legacy files, add redirects, and move attached
files into topic-specific asset folders.
